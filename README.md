# Student Management System

A Flask-based web application for managing student records.

## Features

* Add Student
* Edit Student
* Delete Student
* Attendance Management
* Automatic Pass/Fail Result Generation
* SQLite Database Integration

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS

## How to Run

```bash
pip install -r requirements.txt
python app.py
```

Open:

```
http://127.0.0.1:5000
```
